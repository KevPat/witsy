## D
- **D-01** [Critical] API key storage — `config.ts:481`, `:208`, `:416-439`, `:121-130`, `:472-506` — `saveApiKeys` deletes the key store, then returns true even if `encryptString` throws, and `saveSettings` strips the keys from `settings.json`, so the key is gone from both.
